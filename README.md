# 每日清单（Daily Tasks）v1.21

轻量的本地安卓 App，底部四个页面：**今日清单 / 锻炼 / 消耗品 / 攒钱**。数据全存手机本地（SharedPreferences + JSON），不联网。

## 一、今日清单

### 日期跳转（v1.5）

- 日期条「‹ 10月30日 周五 ›」：‹/› 一天一天翻，点中间日期弹日历跳到任意一天；
- 不是今天时多一个「回到今天」，日期下标「历史记录」或「未来计划」；
- 未来日期勾选框灰显（不能提前打勾），但可在那天新建/编辑/删除任务。

### 小标语（v1.21 按时段分组）

- 「今日清单」大标题右侧显示一句带「」的小标语，单行显示，太长自动省略；
- 点一下看当前标语，可「换一句」手动换，也可「编辑标语分组」；
- **按时段分组（v1.21）**：每组有自己的起止时间（结束早于开始表示跨零点，相同表示全天）、句子列表和轮换周期（分钟，1–1440 可自定义）；
- 默认两组：22:00–07:00 早睡早起组（每 30 分钟换一句）、07:00–22:00 日常组（每 60 分钟）；同组在时段内按周期轮流显示，徽标每 30 秒按手机时间刷新；
- 时段可增删改，句子可逐句改 / 删 / 加；升级时自动把 v1.20 的自定义标语和语句库并入白天组；
- 分组或句子可以为空；没有匹配时段或空组时标题显示默认那句；数据都只存本机。

### 任务

- 行内：勾选框 + 开始时间（等宽 `09:30`）+ 名称 + 分类 + 重复方式 + 必要级标签 + 备注；
- 排序：必要级从高到低，同级按时间；完成状态按天保存，0 点自动重置（每 30 秒查跨天）；
- 超时高亮：只有「今天」且时间已过未完成时时间显示红色；
- 搜索：名称 / 备注 / 分类，× 清空；
- 重名拦截：与已有任务同名（忽略大小写与多余空格）→ 标红 + 禁用保存；编辑自己不算；
- ⋮ 菜单：编辑 / 删除 / **加到系统日历**（v1.11，写进自带日历新建界面，结束 +1 小时，无需权限）/ **推迟一天**（v1.7）。

### 必要级

| 档位 | 含义 | 标签 |
| --- | --- | --- |
| 必要 | 今天必须做完 | 红 |
| 重要 | 最好今天做完 | 橙 |
| 普通 | 有空再做（默认） | 不显示 |

**分色进度条（v1.18）**：顶部进度条按各档任务数分段上色——必要段**红色**、重要段橙色、普通段灰蓝；每段按自己的完成比例填充。所以勾掉一个「必要」任务，进度条上就补上一截红色，一眼看出红任务还剩多少。进度条下方有图例「必要 2/3 · 重要 1/2 · 普通 3/5」。

### 重复规则

| 选项 | 行为 |
| --- | --- |
| 一次性 | 勾完当天仍显示，次日消失 |
| 每天 | 每天都出现 |
| 每 N 天 | 以创建日为基准，每 N 天出现一次（2～60） |

### 推迟一天

只对「非每天」且非「必要」开放；历史/未来日期同样可推迟。两种方式：**只推迟这一次**（当天隐藏、次日补上）/ **之后一起顺延**（每 N 天任务整周期后退一天）。

### 分类

自带 工作/生活/学习/运动，可改名删除；齿轮 → 管理分类（新增、点名字改名、删除→任务变「未分类」）；首页 Chip 筛选，进度跟随。

### 提醒

每个任务单独开关（默认开），只在任务该出现那天按时间提醒；重启/改时区/更新后自动重建闹钟。

## 二、锻炼

### 部位与动作（v1.5）

- 部位自定义：管理部位可增删改；新增部位自动建空计划，改名同步，删除连带删计划（历史记录不受影响）；
- 动作自定义：名称 / 组数 / 次数 / **重量 kg**；
- **动作身份 = 名称 + 次数 + 重量**：任一不同即两个动作，各自显示、各记进度。

### 排序 / 拆分 / 合并 / 分组（v1.7）

- 编辑计划可 ↑/↓ 排序；
- 拆分：一个动作拆成两条（组数不变，各自设次数/重量）；合并：组数相加，次数/重量取所选；
- 编辑动作时直接选「备选组 ① ② …」（v1.17 起不再需要选颜色），同一序号的不同动作今天只做一个；界面显示为 ①② 编号。

### 不同动作 N 选一（v1.8 / v1.15 / v1.16 / v1.17）

- 计划里编了**同一个序号**的不同动作 = 今天练其中一种（如「卧推 / 哑铃卧推」都选 ①）；
- 编号就是组号：选 ① 的两条动作都显示 ①，选 ③ 的显示 ③，弹窗「今天做哪一个」，每组「备选组 ① · N 选一」，行内「组数 × 次数 · 重量」，默认第一个；
- 选部位生成今日清单、导入模板时只要有备选组就弹选择；顶部「同组动作选一（①②）」可重选；
- 同名不同重量/次数**不算**备选组，是同一动作的不同负荷，全部保留。

### 计划表格编辑 + 动作库（v1.9）

- 铅笔按钮打开表格：列「编号 / 动作 / 组数 / 次数 / 重量 / 操作」；每行 ↑/↓，⋮ 菜单「编辑详情/上移/下移/拆分/删除」，同名可「合并」；底部「＋ 加一行动作」「取消/保存」；
- 动作库：卡片网格展示所有出现过的动作（「3 组 × 8 · 60kg」+ 部位），点卡片加进今天。

### 重量与容量（v1.6）

- 每个动作可带重量（kg，可小数），卡片显示「60kg」胶囊或「自重」；
- 训练中点重量胶囊可临时改当天重量（20/30/40/60 快捷值），只影响今天；
- 顶部「今日容量」= Σ（实际组数 × 次数 × 重量）；纯自重显示「—」。

### 记组与保存

单击卡片 +1 组，「−」退回，全完成变绿；顶部总组数进度条；换部位不丢进度（同名动作已点组数保留）；「保存」存进「最近训练」，同一天再进可「恢复上次」或「清空全部组数」。

### 今日锻炼日记（v1.19）

- 「今日训练」大标题右侧有日记入口：没写过显示「写今日日记」，写过显示「日记 · 第一句开头」；
- 点开弹窗写多行文字（今天练的重量、状态、感受……），保存后按当天日期存在本机；
- 换一天就是新的一篇，当天再打开还在；弹窗里可以「清空」这一天。

### 训练进步（v1.21）

- 「最近训练」上方分三张进步卡：推（胸 + 三头 + 肩前中束）、拉（背 + 二头 + 肩中后束）、臀腿（臀腿 + 肩中束）；
- 每张卡显示这一类的最近一次（日期、部位、完成组数、容量）、相对上次的容量或组数变化（+kg / 持平 / 首次记录），以及最近 6 次的容量走势；
- 归类按部位关键词：胸 / 三头 / 肩前 → 推，背 / 二头 / 肩后 → 拉，腿 / 臀 → 臀腿，都不沾边归「其他」。

### 回看训练计划（v1.21）

「最近训练」每条记录可点开（箭头或点文字）：除日期、部位、完成组数 x/y、动作数、总容量外，还能展开看到当时的完整计划——逐个动作的完成组数 / 计划组数、次数、重量。

### 模板（v1.11 独立版块）

- 「模板」→ 训练模板页：卡片（名称、部位、动作带 Ⅰ Ⅱ Ⅲ 负荷），右侧「编辑 / 导入到今日 / 删除」；
- 「新建模板」可独立填名称、勾部位、加动作、从动作库挑、调序，不必先练；
- 改模板不影响当天训练；导入 = 替换今天清单（有备选组先选名字），同名动作已点组数保留；
- 练到一半可「存为模板」（重名自动改为「xxx 2」）。

### v1.15：三板块、层级模板、动作库仓库

- 顶部一排等宽「今日计划 / 训练模板 / 动作库」，其下「加动作 / 身体数据 / 存为模板 / 导入模板」（每行 2 个等宽，自动换行不遮挡）；
- 模板层级：一个动作一张卡（第一层），卡内 Ⅰ Ⅱ Ⅲ 变体（第二层，罗马数字），可整组 ↑/↓，变体可上下调序 / 编辑 / 删除（v1.17 起「加变体」按钮已去掉）；导入只取顶层一个；
- 动作库当仓库：2 列卡片，可配**相册示范图**与**文字说明**，右下角「＋」加进今天；图为持久化 URI。

### v1.16：不同动作的 ①② 备选组

- **模板 Ⅰ Ⅱ Ⅲ**（v1.17 改罗马数字）= 同一动作的不同练法（层级）；**今日清单 ①②** = 不同动作的备选组（只练一个）；
- 计划表格、今日清单、模板卡片不再画色点，改为动作名前显示 ①②（单个不显示）；
- 同名不同负荷永远不算备选组、也不互相覆盖。

### v1.17：备选组直接选序号、罗马数字层级、金币动画修复

- 编辑动作时的「标记颜色」色块改为「备选组」一排胶囊：**不分组 / ① / ② / ③ / ④ / ⑤ / ⑥**，点一下就设好，不用再挑颜色；
- 备选组编号 = 组号（选 ③ 的动作就显示 ③），弹窗里组内选项用「1. 2. 3.」区分，不再和组号混；
- 模板第二层（同一动作的不同重量/次数）改用罗马数字 **Ⅰ Ⅱ Ⅲ**，与顶层的 ①② 一眼分开；
- 删除模板编辑里的「加变体」按钮，变体数量以你实际添加的动作条目为准；
- 存钱罐金币下落动画重写：所有金币在动画前 55% 内依次开始下落、每枚用 40% 时间落地，动画结束时最后一枚也已堆好，不再悬空。

### v1.18：记账式消耗品、编辑界面去重、进度条分色

- 消耗品的「＋」变成「**记一笔**」：填名称 + 价格 + 数量就完成一次购买记账；同名（忽略大小写/空格）自动归档到已有条目，价格追加进价格记录、购买次数 +1、累计花费累加——所以记账时重名是允许的；新名字才新建；
- 弹窗会提示归档目标（已买几次 / 累计花费 / 上次价格），已有记录还能一键点名字；
- 编辑弹窗里删掉了和「用量」重复的「总量」字段，现在只有 **用量（总量）+ 单位** 和可选的 **现在还剩多少**；
- 今日清单进度条改为**按必要级分色分段**：必要（红）/ 重要（橙）/ 普通（灰蓝），各段按完成比例填充，下方带图例。

### 身体数据（v1.12）

- 「身体数据」页：右下角「记一条」→ 日期 + 体重 kg，另可填臂围/腰围/胸围 cm；同一天再记覆盖；
- 表格视图：日期倒序，每周插一行**周平均体重**（自然周，周一起）；
- 曲线视图：体重曲线（每日点 + 周平均粗线）、三围三条线可开关；
- 顶部：最新体重、最近 7 天平均、与上次相比涨跌。

## 三、消耗品

- **记账式入口（v1.18）**：右下角「＋ 记一笔」打开购买弹窗——填名称、价格、数量、日期即可；名称和已有记录相同时（忽略大小写/空格）**自动归档到那条**，价格追加进价格记录、购买次数 +1、累计花费累加，所以记账时可以放心重名；名称是新的才新建一条；
  - 同名时弹窗会提示「已归档到『洗面奶』：已买 3 次 · 累计 ¥125 · 上次 ¥20」；
  - 数量会累加到用量上；如果这件已标记用完，会自动重新开始使用（从这次购买日期算）；
  - 最近常买的 3 条会在弹窗里做快捷 Chip，点一下填名字；
- 字段：名称、类型、开始使用、用完时间（不填 = 在用）、**用量（总量）** + 单位、剩余量（可选）、当前价格、备注；编辑弹窗里「用量」就是总量（v1.18 合并了原来重复的两个字段），只剩「现在还剩多少」可选填；
- **消耗量/剩余量 ⇄ 已用天数**（v1.5）：行内「⇄」互换显示口径；
- **快捷调整剩余量**（v1.7）：`−`/`＋` 步进（总量 ≥100 用 10，否则 1），点数字精确设置（0/25%/50%/75%/全部、输入、±1/±10）；
- **类型下拉与新建**：弹窗列历史 + 新建类型，可滚动，顶部「新建类型」，下方 4 个快捷 Chip；类型/消耗品重名被拦；
- 搜索：名称/类型/备注，标题「匹配 N 条 · 共 M 条记录」；
- **价格历史**（v1.11 / v1.18）：每次「记一笔」都会追加一条价格记录（价格 0 视为不知道，不记）；⋮ →「价格记录」看平均价、最近涨跌、折线、逐条明细；编辑里改价也会记一次；
- **双视图**（v1.11）：标题栏右侧按钮切换「一条条罗列」/「按类型分模块」（记住选择）；分模块为 2 列卡片（类型、N 条、在用 M 件、累计花费），点进类型详情；
- **累计花费**（v1.15/v1.16）：`totalSpent` = 价格记录求和（无记录按当前价算 1 次）；行内「累计花费 ¥x（N 次购买）」，页头「共 N 条 · 在用 M 件 · 累计花费 ¥X」；分类视图、类型详情、饼图金额口径统一；
- 饼图：环形按类型分组，口径可切 金额/数量/次数，**点扇区（或图例）看该类型记录**。

## 四、攒钱（v1.13）

页内两个 Chip：「攒钱目标 / 本月必要开支」。

### 攒钱目标

- 新建目标：想买什么 + 目标金额 + 备注；卡片显示百分比、进度条、已攒/目标、还差；
- 点进**目标专属页**：存钱罐、已攒/目标/还差、编辑/删除目标；
- **存钱罐（v1.21 按百分比铺满）**：金币液面直接按金额百分比上涨，罐内是交错的金币纹理、上沿有起伏，攒到 100% 时刚好填到投币口下方；进入时液面从 0 平滑涨到当前进度；攒够显示「攒满啦 🎉」；
- **攒钱任务（v1.16 两类）**：
  - **里程碑**：设总次数（如「跑 30 次」），完成一次攒一次，做满结束，显示「已完成 x/N 次 · 还差 M 次」；
  - **日常积累**：每天可做，可设「每天最多领几次」（留空不限），0 点恢复；
  - 均可设金额，「完成 +¥x」入账，⋮ 编辑/删除；提示「今天还能攒 ¥x」；
- 攒钱记录：时间倒序，⋮ 撤销（金额退回）。

### 本月必要开支

- 「添加开支」：名称 / 每月金额 / 备注；
- 汇总卡：本月合计、已预留、**还需预留**（大字）、进度、「还剩 N 天，平均每天再留 ¥x」；
- 勾选 = 本月已预留（按「年-月」记，换月重置）；⋮ 编辑/删除；
- **递减预算（v1.14）**：开关「逐日 / 逐几日降低」+ 每隔几天 / 每次减少多少；从本月 1 号起算，扣到 0 为止；列表「今天还剩 ¥x」+「每天 −¥100 · 本月 ¥3000 · 下次 M/d」/「已用完」，汇总按今天剩余。

## 分享与下载

- 安装包在 Releases 页面：本仓库 → **Releases** → 最新版本 → 下载 `每日清单-1.21.apk`（约 13.8 MB）；

## 需要注意

- 本机未连手机、无模拟器：APK 是**编译 + 177 单测通过、未真机验证**的；闪退请告知现象。
- 锻炼页第一排「今日计划/训练模板/动作库」，第二排「加动作/身体数据/存为模板/导入模板」（每行 2 个等宽）。
- 两套编号别混：模板 Ⅰ Ⅱ Ⅲ（v1.17 起罗马数字）= 同一动作练法；今日清单 ①② = 不同动作备选组。
- 备选组直接在编辑动作时选「不分组 / ① / ② …」，编号即组号；同一组的动作今日清单里只出现一个。
- 动作库图片为持久化 URI：清数据/换机会失效，文字仍保留。
- 累计花费 = 价格记录之和（无记录按当前价算 1 次）。
- 递减预算按日期推算（没花钱也扣），换月从新 1 号重算；预留状态也按月份重置。
- 里程碑做满不能再领；日常任务 0 点重置次数。
- 存钱罐液面 = 完成度百分比，金币只是罐内纹理，不再按 100 枚封顶。
- 删除目标连记录一起删，不可恢复；覆盖安装保留数据，卸载会清空。
- debug 签名仅供自用；国产 ROM 可能需允许自启动/后台弹窗。
- 「每 N 天」以创建/修改当天为第 0 天。
- 一次性任务勾完次日消失；重名只忽略大小写与空格。
- 训练保存按天覆盖；换部位按动作身份保留已点组数；拆分要求 ≥2 组，合并超 20 组截断。
- 体重/三围同日覆盖；周平均只统计有体重的天。
- 锻炼日记按天保存，只影响当天。
- 小标语按手机当前时间匹配时段组；时段重叠时列表里靠前的先生效，空组显示默认句。
- 标语分组和句子保存在本机，轮换周期按分钟自定义（1–1440）。
- 加到系统日历只是复制，之后改任务不会同步。
